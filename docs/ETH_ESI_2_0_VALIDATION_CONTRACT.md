# ETH ESI 2.0 — 고정 수집·검증 계약 (2026-10-27)

## 호출과 적용 범위
사용자 호출은 **"이더 보고서"** 한 마디로 충분하다. 7개 지표: 매크로·지정학 20%, ETH 현물 ETF 15%, 현물 거래량·CVD 18%, OI·펀딩비 20%, ETH 가격·기술적 분석 12%, ETH/BTC 10%, 청산·롱숏스퀴즈 5%. 합계 100%. 스테이블코인과 엘리엇 파동은 제외한다. 피보나치, 지지저항, RSI, MACD, 이동평균선은 유지한다.

## 데이터 수집을 보고서 작성보다 먼저 수행
1. 보고서 시각을 KST로 기록하고 **직전 보고서 이후 발생한 모든 위험/완화 알림**을 먼저 수집한다. 알림의 관측시각, 알림시각, 방향, 수치를 구분한다. 접근할 수 없는 알림은 '미확인'으로 표시한다.
2. ETH/USD 또는 ETH/USDT OHLCV를 충분한 길이(최소 250개 이상의 **완료된 일봉**과 **완료된 주봉**, 가능하면 더 긴 구간)로 가져와 RSI(14), MACD(12,26,9)의 MACD선·시그널선·히스토그램, SMA20·50·100·200을 **각각 일봉과 주봉**으로 계산한다. 일봉·주봉이 아직 끝나지 않았다면 진행 중 캔들을 제외하고 기준 종료시각을 적는다. 같은 거래소/통화쌍을 유지한다. 외부 기술지표 값과 직접 계산 값이 다르면 계산 방식·캔들 종료시각·거래소를 대조한다. 조회/계산을 시도하지 않고 '미확인'으로 처리하는 것은 금지한다.
3. Binance ETH/USDT 현물과 Kraken ETH/USD 현물 CVD JSON의 calculated_at_utc, latest_trade_utc, 각 구간 coverage_status, data_completeness를 읽는다. 5m·15m·1h·4h·24h 매수·매도량과 순차이를 표시한다. **두 거래소 구간 종료시각과 완전성이 충분할 때만 확정 합산**한다. unverified 구간은 합산 확정 금지. aggTrade buyer-maker 기반 수치는 해당 방법을 명시한다.
4. ETH 가격·거래량, OI(거래소와 집계 범위 명시), 펀딩비(8h 환산 명시), 롱/숏 청산 분리, ETF 일별/누적 순유입, ETH/BTC, Fed·10년물·DXY·CPI/PCE·고용·BOJ·USD/JPY·브렌트유·지정학을 조회한다. 모든 항목에 출처·관측시각·상태를 붙인다.
5. 180일 백데이터를 읽고 **현재 관측 조합과 정의가 같은 표본만** 비교한다. 과거 빈도를 현재 예측 확률로 표시하지 않는다.

## 상태 관리 / 실패 정책
각 데이터 항목은 {source, observed_at_utc, fetched_at_utc, timeframe, value, status, failure_reason}을 갖는다. status는 VERIFIED / PROVISIONAL / STALE / UNAVAILABLE / NOT_ATTEMPTED 중 하나. NOT_ATTEMPTED를 UNAVAILABLE로 바꿔 쓰지 않는다. 관측 시각이 서로 다르면 최신 실측인 것처럼 섞지 않는다. 원천 API 차단(예: Binance HTTP 451)은 그대로 기록한다. 데이터가 부족하면 검증된 부분 보고서는 작성할 수 있으나 **'완전한 실시간 보고서'로 표시하지 않는다**.

## 점수 및 검산
지표별 점수 0~100 × 가중치/100 = 가중 기여도. 7개 가중치 합계 100 검산. 누락 지표를 50점으로 대체하지 않는다. 새로 채점하지 않은 과거 점수의 단순 재가중 결과는 반드시 **'과거 점수 환산 참고값'**으로 표시한다. 현재 ESI는 근거가 충분한 경우에만 확정한다. 최종 표의 합산값과 머리말 수치가 동일해야 한다.

## 고정 보고서 구조
종합 판단 → 1) 7개 지표 점수표/그래프 2) 매크로·지정학 3) ETH 현물 ETF 4) 현물 거래량·CVD 5) OI·펀딩비 6) ETH 가격·기술적 구조(일봉/주봉 RSI/MACD/SMA 필수) 7) ETH/BTC 8) 청산·롱숏스퀴즈/180일 데이터 9) 지표 간 교차 검증 10) 상승 조건까지의 거리 11) 24시간·7일·30일·90일 조건부 전망과 대응 12) 최종 결론.
