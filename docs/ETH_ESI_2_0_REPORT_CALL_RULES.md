# '보고서' 호출 규칙 — ETH ESI 2.0 (2026-10-27 KST)

사용자가 **보고서** 또는 **이더 보고서**라고 입력하면 `docs/ETH_ESI_2_0_CANONICAL_REPORT.md`와 `docs/ETH_ESI_2_0_VALIDATION_CONTRACT.md`를 읽고, 해당 정본의 7지표·12개 본문 항목·가중치·기존 자료를 변경하지 않고 실행한다.

## 출력 구성
- 종합 판단 → 정본 1~12항목 전체 → **13. 최종 결과 요약 — 180일 백데이터 통합**을 마지막에 반드시 추가한다.
- 13항목에는 7지표 결과, 현재 수급·기술적 구조, 180일 백데이터 표본(전체 47건 24h/72h 상승 31/31; 양쪽 매도+OI 감소 32건 19/23; 양쪽 매도+OI 증가 14건 11/8), 역사적 비율, 현재 관측 조건과의 일치/불일치, 24h·72h 해석, 최종 위험/반등/추세 판정을 포함한다.
- 과거 상승 발생 비율은 현재 상승 예측 확률로 표시하지 않는다. 하위 조건 32+14=46건과 전체 47건의 차이를 임의로 채우지 않는다.
- 스테이블코인·엘리엇 파동은 제외한다. 정본 원본 파일 및 백데이터는 보존한다.

## 호출 때마다 최신 자료 조회
1. KST 현재 시각을 확인하고 GitHub `eth_technical_latest.json`, `cvd_latest.json`, `binance_cvd_latest.json`를 실제로 읽는다. 완료 일봉/주봉 RSI14, MACD(12,26,9) 선·시그널·히스토그램·이전값, SMA20/50/100/200을 누락하지 않는다. 이미 연결된 RSI/MACD를 '미연결'이라고 표기하지 않는다.
2. 매크로·ETF·가격·ETH/BTC·거래소별 OI/펀딩·선물 CVD·청산·알림과 180일 데이터는 실제 출처에서 가능한 한 최신 조회하고 관측시각·집계범위·완전성을 검사한다. CVD 합산은 충분히 검증된 경우에만 확정한다.
2-1. OI 보조 원천으로 GitHub `eth_oi_okx_latest.json`을 조회하고, `status=VERIFIED` 및 `observed_at_utc`의 신선도를 검증한 경우에만 OKX ETH-USDT-SWAP 단일 거래소 OI(ETH 단위)로 표기한다. Binance OI 또는 시장 전체 OI로 혼동하거나 다른 거래소 수치와 단순 합산하지 않는다. 이 파일이 없거나 오래되면 최신값으로 표시하지 않는다. 기존 보고서 화면 양식과 7지표 가중치는 변경하지 않는다. 
3. 이전 검증값→최신값·변화와 기준시각을 명확히 병기한다.
4. **'미산출', '보류'라는 문구를 반복하는 대신**, 계산 가능한 것은 반드시 계산하고 조회 가능한 것은 조회해 완성된 결과를 제시한다. 그러나 실제 최신 데이터가 확보되지 않은 항목을 과거값으로 현재값처럼 위장하거나 임의 숫자·확률·ESI 점수를 만들어내지 않는다. 조회 실패/불완전 상태는 사실대로 간결히 밝힌다. 필요한 데이터가 없으면 현 시점 완전 실시간 확정 보고서라고 주장하지 않는다.
5. 최신 7지표 점수를 실제 근거로 모두 재평가한 경우에만 현재 ESI 확정 점수를 표시한다. 정본의 32.98/100은 과거 환산 참고값이다.

이 파일은 보고서 호출/출력에 관한 **저장된 사용자 선호 및 실행 지침**이다. GitHub에 저장하는 것만으로 ChatGPT 전역 단축 명령이나 예약 작업의 실행 코드가 자동 변경되지는 않는다.

## 화면 양식 고정 — 사용자 확정 요청 (2026-10-27)
- **기존에 합의된 보고서의 시각적 양식을 최우선**으로 한다. 항목만 일치시키고 첫 화면·표·차트·최종 결과의 배치를 임의 변경하지 않는다.
- 첫 화면을 '종합 판단'이라는 긴 글머리표 설명이나 **과거 32.98/100의 대형 점수 카드/진행 막대**로 시작하지 않는다. 32.98은 오직 '과거 참고 점수'로 작게 표시한다.
- 첫 화면 기본 순서: 제목 'ETH ESI 2.0 | 7지표 통합 상세 보고서' → 정확한 KST 보고서 기준시각 및 데이터별 관측시각 → 현재 시장 방향성/위험 판정과 긍정·위험·유의 각각 간결한 요약 → **1. 7지표 가중 평가표**. 이어서 정본의 2~12항목, 마지막 13항목을 순서대로 출력한다. 이전에 사용자가 확정한 실제 첫 화면 템플릿이 있으면 그 화면을 이 기본 순서보다 우선한다.
- 7지표는 고정 순서와 20/15/18/20/12/10/5 가중치, 각각의 점수·가중 기여도·평가 근거를 표로 보여주고 필요한 차트를 붙인다. 일봉·주봉 RSI/MACD/SMA, 거래소별 5m/15m/1h/4h/24h CVD 표를 빠뜨리지 않는다.
- 마지막 **13. 최종 결과 요약 — 180일 백데이터 통합**은 과거 전체 47건, 24h/72h 상승 31/31건, 양쪽 매도+OI 감소 32건(19/23), 양쪽 매도+OI 증가 14건(11/8), 현재 조건 일치 여부, 24h·72h 반등/지속성 해석, 최종 결론을 표·그래프와 함께 작성한다.
- 가능한 수치는 매번 조회·계산해 보고서를 완성하되, 출처가 없는 숫자를 만들거나 과거값을 실시간으로 위장하지 않는다. 데이터가 실제로 확보되지 않았다면 사유와 마지막 검증 시각을 명확히 밝힌다.
- **이 파일만으로 과거 보고서의 실제 픽셀 단위 레이아웃을 복원할 수는 없다.** 정확한 원본 화면 재현이 필요하면 사용자가 확정한 원본 보고서 전체를 별도 템플릿으로 저장하고 그 파일을 우선 참조한다.
